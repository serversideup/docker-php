::lead-p
The images add helper commands to `/usr/local/bin` for installing packages and extensions, fixing file permissions, and checking Laravel processes.
::

Every command from the [official PHP image](https://hub.docker.com/_/php){target="_blank"}, such as `docker-php-ext-install` and `pecl`, also works. The images run as `www-data`, so commands marked **Requires `USER root`** need `USER root` in your Dockerfile and `USER www-data` again afterward.

::command-explorer
::
