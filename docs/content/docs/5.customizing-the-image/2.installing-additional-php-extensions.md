::lead-p
Every image includes [`install-php-extensions`](https://github.com/mlocati/docker-php-extension-installer){target="_blank"}, which installs an extension and the system packages it needs on both Debian and Alpine. Run it in your `Dockerfile` as `root`.
::

## Add extensions in your Dockerfile
The images run as the unprivileged `www-data` user, so switch to `root` to install and switch back afterward:

::code-tree{defaultValue="Dockerfile"}

```dockerfile [Dockerfile]
FROM serversideup/php:8.5-fpm-nginx

USER root
RUN install-php-extensions intl bcmath
USER www-data
```

```yaml [compose.yml]
services:
  php:
    build: .
    ports:
      - 80:8080
    volumes:
      - .:/var/www/html
```

::

Build and start the container. `--build` rebuilds the image when the `Dockerfile` changes:

```bash [Terminal]
docker compose up --build
```

Check that the extensions loaded:

```bash [Terminal]
docker compose exec php php -m | grep -E 'intl|bcmath'
```

To build your code into the same image for production, see [packaging your app for deployment](/docs/deployment-and-production/packaging-your-app-for-deployment).

## Which extensions you can install
`install-php-extensions` supports most PECL and bundled extensions across PHP versions. See its [list of supported extensions](https://github.com/mlocati/docker-php-extension-installer#supported-php-extensions){target="_blank"}. The extensions already in each image are on the [default configurations](/docs/getting-started/default-configurations) page.

`intl` is a common addition. It isn't included by default because of its size, but Laravel's `email` validation rule needs it for the [`dns` and `spoof` checks](https://laravel.com/docs/validation#rule-email){target="_blank"}.

Can't find the extension you need? [Ask in GitHub Discussions](https://github.com/serversideup/docker-php/discussions/new?category=q-a){target="_blank"}.
